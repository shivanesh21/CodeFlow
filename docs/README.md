# CodeFlow

## Interactive JavaScript Code Execution Visualizer

CodeFlow is a MERN Stack web application that helps users understand how JavaScript code executes internally through interactive visualizations.

## Features

- Monaco Code Editor
- Step-by-Step Execution
- Variable Tracking
- Call Stack Visualization
- Heap Memory Visualization
- Console Output
- Save Code Snippets
- Execution History
- JWT Authentication
- Responsive Dashboard

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Monaco Editor

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT
- bcrypt
